## ⚪ 사용자 선처리 트랙 (본 보고서 배포 전 머지 완료)

본 보고서 배포 *이전* 에 사용자가 공용 인프라 / 다른 작업의 전제조건 항목을 일괄 처리한 트랙입니다. **각 담당자는 본 영역을 다시 손대지 않습니다.** 자기 작업 시 영향 범위 파악 용도로만 참고.

### A. 처리된 변경 내역

- **`App.tsx`** — `QueryClient` `defaultOptions: { queries: { retry: 1, throwOnError: false } }` 명시 (컨벤션 11장). REST `.parse()` throw 가 React Query `error` 상태로 안전 캡처되는 안전망 정착.
- **`shared/hooks/useModal.ts`** — a11y 골격 추가: `containerRef` 반환, 모달 컨테이너로 자동 포커스(첫 focusable 직행 금지 — Enter key-repeat 사고 방지), 트리거 요소로 포커스 복귀, Tab/Shift+Tab focus trap.
- **`shared/components/PixelModal.tsx`** — `is-rounded` ↔ `with-title` 사이 공백 누락 fix + `role="dialog"`/`aria-modal="true"`/`aria-labelledby`/`tabIndex={-1}` + `containerRef` 부착 (19장 정착 예시).
- **`config/env.ts`** — Zod 스키마 검증 + 키 확장(`POSTHOG_KEY`, `POSTHOG_HOST`, `SENTRY_DSN`, `FARO_URL`, `MODE`). 12장 fail-fast 적용.
- **`main.tsx`, `lib/faro.ts`, `providers/PostHogProvider.tsx`** — `import.meta.env` 직접 접근을 `env.*` 로 일괄 이전. PostHogProvider 에 빈 키 가드(`if (env.POSTHOG_KEY) posthog.init(...)`) 추가 (18장).

### B. 각 담당자에게 미치는 영향

- **모든 도메인** — REST API `.parse()` 사용 시 throw가 안전하게 React Query error로 캡처됨 → 컨벤션 3장(`.parse()` 허용) 안심하고 적용 가능
- **모달 보유 도메인 (전은진/이유정)** — `useModal()`이 반환하는 `containerRef`를 모달 컨테이너에 부착 + `role`/`aria-modal`/`aria-labelledby` 직접 부여 패턴으로 a11y 마이그레이션. 참고 예시: `shared/components/PixelModal.tsx`
- **환경변수 신규 사용 시** — `import.meta.env` 직접 접근 금지, `import { env } from '@/config/env'` 만 사용. 새 키 추가 시 `config/env.ts`의 `envSchema`에 먼저 추가
