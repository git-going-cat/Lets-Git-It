# 도감 모달 UI 구현 및 API 연동

### Background / Context
- 사용자들이 명령어(Command)에 대한 상세 정보(옵션, 인게임 사용 여부 등)를 파악할 수 있도록 도감(Dictionary) 기능이 필요했습니다.
- 전역 상태 없이 모달 내에서 개별적으로 상태를 관리하며, React Query를 통해 데이터를 불러오는 패턴을 유지하고자 했습니다.

### Decision
- **상태 관리**: 전역 상태(Zustand 등)를 배제하고 `DictionaryModal` 내에서 `searchQuery`와 `selectedCommand` 상태를 관리하도록 결정했습니다.
- **데이터 페칭**: `TanStack Query`의 `useQuery`를 활용해 데이터를 캐싱하고 (`staleTime: Infinity`), `select` 옵션을 사용하여 바로 `commands` 배열을 반환받아 컴포넌트 복잡도를 낮췄습니다.
- **UI 레이아웃**: 공통 Windows 11 Fluent Design 톤을 유지하는 오버레이와 카드 디자인을 적용하여 2패널(좌측 명령어 목록, 우측 상세 정보) 구조로 구현했습니다.

### Why
- 명령어 도감 데이터는 자주 변동되지 않으므로, `staleTime`을 무한으로 설정하여 불필요한 네트워크 요청을 줄이는 것이 최적이라 판단했습니다.
- 클라이언트 사이드 검색을 도입해 즉각적인 피드백을 제공함으로써 UX를 개선했습니다.

### Caution
- 이미지 URL(`imageUrl`)이 존재하지 않을 경우를 대비해, 있을 때만 렌더링하도록 안전하게 처리했습니다.
- `api/dictionaryApi.ts`에서 공통 `http` 인스턴스(`@/core/http`)를 통해 요청하므로, 토큰이나 공통 에러 처리가 일관되게 동작합니다.

### Test Plan
- 모달을 열었을 때 데이터 페칭 로딩 스피너가 표시되고 데이터가 그려지는지 확인.
- 검색 입력 시 대소문자 관계없이 목록이 올바르게 필터링되는지 확인.
- 명령어 선택 시 우측 패널에 상세 정보와 함께 게임 내 사용 가능 여부 뱃지가 렌더링되는지 확인.
