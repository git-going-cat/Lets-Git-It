# 대기실 채팅 레이아웃 보정

## Background / Context

대기실 화면에서 채팅 영역이 남은 높이를 모두 차지하면 방 정보, 플레이어 목록, 준비 상태 UI와 함께 배치될 때 화면 균형이 깨질 수 있었다.

채팅 메시지가 많아지는 경우 전체 대기실 레이아웃이 밀리는 대신 채팅 메시지 영역 내부에서만 스크롤되어야 한다.

## Decision

`WaitingRoomChat`의 루트 높이를 고정 높이 영역으로 조정하고, 메시지 리스트에는 `min-h-0`과 `overflow-y-auto`를 적용했다.

입력값이 비어 있을 때의 안내 문구는 "메시지를 입력해 주세요."로 띄어쓰기만 보정했다.

## Why

Flex 자식 요소에서 스크롤 영역이 의도대로 줄어들려면 `min-h-0`이 필요하다. 이를 지정하지 않으면 내부 스크롤 대신 부모 레이아웃이 커지는 문제가 생길 수 있다.

## Caution

채팅 높이는 대기실 레이아웃에 맞춘 값이다. 플레이어 패널 높이나 대기실 전체 그리드가 바뀌면 채팅 높이도 함께 재검토해야 한다.

## Test Plan

- 대기실 진입 후 채팅 영역이 고정 높이로 표시되는지 확인한다.
- 메시지가 채팅 영역을 넘을 때 메시지 리스트 내부에서만 스크롤되는지 확인한다.
- 빈 메시지 전송 시 안내 문구가 표시되는지 확인한다.
- `npm run lint`와 `npm run build`를 실행한다.
