# Git 타이핑 게임 프로젝트 온보딩 문서

## 1. 프로젝트 개요

### 핵심 컨셉
- **장르**: 실시간 멀티플레이어 타이핑 게임
- **주제**: Git 명령어 학습 및 연습
- **비주얼**: 아이소메트릭 픽셀 아트 기반
- **스토리**: 개발자가 고양이가 만든 악성코드로 인해 컴퓨터 속에 갇혀, Git 프로젝트를 완성해야 탈출할 수 있는 설정

### 기술 스택
- **프론트엔드**: React + WebSocket
- **백엔드**: Spring Boot + WebSocket
- **인프라**: AWS EC2 (Seoul), Redis (동일 리전), RDS MySQL 8.0
- **배포**: Nginx (리버스 프록시)

## 2. 게임 모드 구조

### 2.1 싱글 모드
- **난이도**: Easy / Normal / Hard
- **목숨**: 3개
- **게임 시작**: `git clone` 명령어 입력으로 시작
- **점수 계산**: 시간, 목숨, 콤보, 오타 수를 고려한 감점제

#### 난이도별 차이점
| 난이도 | 브랜치 수 | 명령어 제시 | Conflict 미니게임 | 명령어 범위 |
|--------|----------|------------|------------------|------------|
| Easy | 최대 3개 | switch 포함 모든 명령어 제시 | 없음 | add, commit, push, merge, switch, pull |
| Normal | 최대 4개 | switch 제외하고 제시 | 없음 | Easy + fetch |
| Hard | 최대 5개 | switch 제외하고 제시 | 있음 (방향키 시퀀스) | Normal + rebase, force push, diff |

#### 점수 계산 공식
- 만점 = 완료 단어 수 × 1000
- 최종 점수 = max(0, 만점 − 시간감점 − 오타감점 − 목숨감점)
- 시간감점 = (경과시간 / 제한시간) × 만점 × 0.40
- 오타감점 = (오타수 / 총시도수) × 만점 × 0.35
- 목숨감점 = (잃은목숨 / 최대목숨) × 만점 × 0.25

#### 아이템 시스템
- **획득**: 랜덤으로 명령어에 포함 (최대 3개/판)
- **사용**: Ctrl + 1/2/3
- **종류**:
    - 1번 슬롯: `stash` (명령어 멈추기)
    - 2번 슬롯: `cherry-pick` (명령어 제거)
    - 3번 슬롯: `restore` (목숨 1개 회복)

### 2.2 멀티 모드 - 기여도 뺏기
- **인원**: 2~4명
- **목표**: 제한 시간 내 가장 많은 커밋 성공
- **특징**: 순서 무관, 먼저 입력한 사람이 기여도 획득
- **브랜치**: 플레이어 수 × 2개
- **명령어 수**: 총 30개
- **기여도 계산**: (해당 플레이어 성공 명령어 수) / (지금까지 등장한 전체 명령어 수) × 100
  - 분모는 성공 여부와 무관하게 지금까지 등장한 명령어 수 기준 (만료 포함)
  - 예: 명령어 1개 등장 후 플레이어 A가 성공 → A 100% / 명령어 2개 등장 후 B가 성공 → A 50%, B 50%
- **고양이(CAT) 기여도**: 제한 시간 내 아무도 입력하지 못해 만료(miss)된 명령어의 기여도는 고양이에게 귀속된다.
  - 고양이 기여도 = (만료된 명령어 수) / (전체 등장 명령어 수) × 100
  - 고양이는 게임 내 순위에 플레이어와 동일하게 포함된다.

#### 예외 상황
- 동시 입력: 랜덤으로 1명 선택
- 플레이어 이탈: 기여도 0으로 처리, 1명 남으면 즉시 종료

### 2.3 멀티 모드 - 타임어택
- **인원**: 2명
- **제한 시간**: 3분
- **목표**: main 브랜치에 가장 많은 커밋 push
- **브랜치 구조**: 유저1 브랜치 | main 브랜치 | 유저2 브랜치

#### 게임 진행
1. 각 브랜치에 5개 명령어 생성
2. 하나 제거 시 새 명령어 자동 추가
3. push 시 conflict 발생 가능 → 미니게임 해결 필요
4. Conflict 미니게임: (push 명령어 수 × 2)개의 방향키 시퀀스

#### Conflict 미니게임
- **판정**: 프론트엔드 자체 처리
- **실패 시**: 서버 통신 없이 프론트 재시작
- **성공 시**: 서버에 전송

### 2.4 멀티 모드 - 협력 게임
- **인원**: 4명 고정
- **목표**: 목표 형상을 정확한 순서로 완성
- **난이도**: 1~5단계 (맵별)

#### 게임 플로우
1. **명령어 공개 단계 (3초)**
    - 총 20개 명령어를 4개씩 5세트로 구성
    - 명령어 4개와 순서를 3초간 공개

2. **명령어 배정 단계**
    - 카드 뒤집기 → 야바위처럼 섞기 → 플레이어별 1개씩 랜덤 배정
    - 각 플레이어는 자신의 명령어만 확인 가능

3. **입력 단계**
    - 기억한 순서대로 1명씩 순서대로 입력
    - 오타 발생 시: 엔터 클릭 시 알림 (재입력 가능)

4. **리셋 조건**
    - 순서 잘못 입력 시 즉시 사이렌 효과 → 해당 판 전체 리셋
    - 리셋 시: 잘못 입력한 사용자가 `git reset` 입력 → 동일 세트 재공개 → 재배정

5. **성공 조건**
    - 4개 명령어 모두 올바르게 입력 시 다음 세트로 진행
    - 5세트 완료 시 게임 종료

#### 예외 상황
- 플레이어 이탈: 즉시 게임 종료 → 대기실 이동

## 3. 핵심 시스템

### 3.1 인증 시스템
- **로컬 회원가입**: 이메일 + 비밀번호
- **OAuth 소셜 로그인**: 지원
- **첫 방문 시**: 인트로 영상 → 튜토리얼 → 닉네임/캐릭터 설정

### 3.2 튜토리얼
- **범위**: 모든 모드 공통 요소만 포함
- **내용**:
    - 기본 입력 방법 (타이핑 + Enter)
    - 게임 시작 (`git clone`)
    - 일시정지 (ESC 또는 pause 아이콘)
    - 아이템 사용법 (Ctrl + 1/2/3)

### 3.3 랭킹 시스템
- **싱글 모드**: 난이도별 최고 점수
- **기여도 뺏기**: 최고 기여도 수
- **타임어택**: 누적 커밋 수 (주차별 갱신)
- **협력 모드**: 최고 기록 (소요 시간 기준, 동점 시 맵 난이도 우선)
- **갱신 주기**: 주차별 (전 주 랭킹은 명예의 전당)

### 3.4 도감 시스템
- **구성**: 명령어별 그림(브랜치), 명령어, 옵션, 설명
- **조건**: 해금 시스템 없음 (모든 명령어 공개)

### 3.5 마이페이지
- **조회 가능 정보**:
    - 모드별 최고 기록
    - 총 플레이 시간
    - 전적 (난이도별, 모드별)
    - 캐릭터 변경
    - 닉네임/비밀번호 수정

## 4. 방 시스템 (멀티 모드)

### 4.1 방 생성
- **모드 선택**: 기여도 뺏기 / 타임어택 / 협력
- **방 코드**: 영문+숫자 6자리 (시스템 자동 생성)
- **비밀번호**: 숫자 4자리 (선택)
- **공개/비공개**: 설정 가능

### 4.2 방 참가
- **방법**:
    - 방 리스트에서 선택
    - 방 코드 직접 입력
- **필터링**: 게임 종류별 (3종)
- **비밀방**: 비밀번호 입력 필요

### 4.3 대기실
- **공통 기능**: Ready 버튼, 채팅
- **방장 권한**:
    - Start 버튼
    - 모드 변경
- **방장 이탈 시**: 랜덤으로 새 방장 지정

### 4.4 게임 시작 조건
- 인원수 제한 충족 여부 확인
- 조건 미충족 시: 안내창 + 시작 불가

## 5. 게임 진행 세부 사항

### 5.1 명령어 시나리오
- **구성**: 난이도별 3개 시나리오 (커맨드 템플릿)
- **제공**: 게임 시작 시 랜덤 1개 선택
- **순서**: 시나리오 내 명령어 순서 고정
- **커밋 메시지**: 서버에서 랜덤 제공

### 5.2 게임 종료 조건
- **싱글 모드**:
    - 목숨 3개 모두 소진
    - 모든 명령어 완료 (프론트 카운트 기준)
- **기여도 뺏기**:
    - 제한 시간 종료
    - 1명만 남은 경우
- **타임어택**:
    - 3분 경과
    - 1명만 남은 경우
- **협력 모드**:
    - 20개 명령어 모두 완료
    - 플레이어 이탈

### 5.3 결과 화면
- **싱글 모드**: 점수, 브랜치 전체 모양, 다시하기/랭킹/홈
- **기여도 뺏기**: 기여도, 등수, 마무리 영상 (1등: 탈출 / 나머지: 갇힘). 고양이(CAT)도 순위에 포함되며, 고양이가 1등인 경우 `winnerVideoTarget`은 null.
- **타임어택**: 각 유저 커밋 수, 승자 표시
- **협력 모드**: 완성 형상 이미지, 소요 시간

## 7. 스토리 및 연출

### 7.1 인트로 영상
1. 재택 근무 중인 개발자
2. 개발자 부재 시 고양이가 키보드 입력 (악성코드 발생)
3. 개발자가 컴퓨터 속으로 흡입
4. 프로젝트 완성으로 탈출 가능

### 7.2 게임 내 설정
- **싱글 모드**: 고양이가 개발, 사용자(개발자)가 Git 메시지 입력
- **보상**: 츄르 (제대로 완성 시 츄르와 함께 탈출)
- **아이템 시각화**: `cherry-pick` 사용 시 고양이 발바닥 표시

### 7.3 마무리 연출
- **기여도 뺏기 1등**: 탈출 영상
- **기여도 뺏기 나머지**: 컴퓨터 갇힘 영상
- **협력 모드**: 완성 형상 이미지 표시

## 12. 용어 정리
- **판**: 4개 명령어 1세트 (협력 모드)
- **세트**: 명령어 묶음 단위
- **시나리오**: 미리 정의된 명령어 템플릿
- **기여도**: 성공 커밋 수 기반 비율 (기여도 뺏기 모드)
- **목표 형상**: 완성해야 할 브랜치 구조 (협력 모드)
