git-mktag(1)
============

NAME
----
git-mktag - 태그 객체를 추가 검증과 함께 생성

SYNOPSIS
--------
[verse]
'git mktag'

DESCRIPTION
-----------

표준 입력에서 태그의 내용을 읽어 태그 객체를 생성합니다. 출력은 새로운 태그의 <object> 식별자입니다.

이 명령은 linkgit:git-hash-object[1] 에서 `-t tag -w --stdin` 옵션을 사용하여 호출한 것과 거의 동일합니다. 즉, 다음 두 명령어 모두 `my-tag`에 있는 태그를 생성하고 기록합니다:

    git mktag <my-tag
    git hash-object -t tag -w --stdin <my-tag

차이점은 mktag가 태그가 linkgit:git-fsck[1] 검사를 통과하지 못하면 쓰기 전에 종료한다는 것입니다.

mktag에서 수행하는 "fsck" 검사는 linkgit:git-fsck[1] 이 기본적으로 실행하는 것보다 엄격하며, 모든 `fsck.<msg-id>` 메시지가 경고에서 오류로 승격되므로 e.g. "tagger" 줄이 없는 경우 오류가 발생합니다.

객체의 추가 헤더 또한 mktag에서는 오류로 처리되지만 linkgit:git-fsck[1] 에서는 무시됩니다. 이 추가 검사는 적절한 `fsck.<msg-id>` 변수를 설정하여 비활성화할 수 있습니다:

    git -c fsck.extraHeaderEntry=ignore mktag <my-tag-with-headers

OPTIONS
-------

--strict::
	기본적으로 mktag는 linkgit:git-fsck[1] `--strict` 모드에 해당하는 기능을 활성화합니다. 이를 비활성화하려면 `--no-strict`를 사용하십시오.

Tag Format
----------
이 명령의 표준 입력으로 제공될 태그 서명 파일은 매우 간단한 고정 형식을 가집니다: 네 줄의

  object <hash>
  type <typename>
  tag <tagname>
  tagger <tagger>

이후에 '선택적' 자유 형식 메시지가 이어집니다 (이전 Git 버전에서 생성된 일부 태그에는 `tagger` 줄이 없을 수 있습니다). 메시지는 존재할 경우 헤더와 빈 줄로 구분됩니다. 메시지 부분에는 Git 자체가 신경 쓰지 않지만 gpg로 확인할 수 있는 서명이 포함될 수 있습니다.
