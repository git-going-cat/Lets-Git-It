git-rev-list(1)
===============

NAME
----
git-rev-list - 커밋 객체를 역시간순으로 나열

SYNOPSIS
--------
[verse]
'git rev-list' [<options>] <commit>... [--] [<path>...]

DESCRIPTION
-----------

:git-rev-list: 1
include::rev-list-description.adoc[]

'rev-list'는 커밋 계보 그래프를 구축하고 탐색할 수 있게 해주므로 필수적인 Git 명령어입니다.
이러한 이유로 'git bisect' 및 'git repack'와 같이 다양한 명령에서 사용할 수 있도록 많은 옵션을 제공합니다.

EXAMPLES
--------

* 현재 브랜치에서 도달 가능한 커밋 목록을 출력합니다.
+
----------
git rev-list HEAD
----------

* 현재 브랜치에 있지만 업스트림 브랜치에는 존재하지 않는 커밋 목록을 출력합니다.
+
----------
git rev-list @{upstream}..HEAD
----------

* 커밋을 작성자와 커밋 메시지와 함께 형식화합니다 (porcelain linkgit:git-log[1] 참조).
+
----------
git rev-list --format=medium HEAD
----------

* 커밋을 해당 diff와 함께 형식화합니다 (porcelain linkgit:git-log[1] 참조. 이는 단일 프로세스에서 수행할 수 있습니다).
+
----------
git rev-list HEAD |
git diff-tree --stdin --format=medium -p
----------

* `Documentation` 디렉토리의 파일을 변경한 현재 브랜치의 커밋 목록을 출력합니다.
+
----------
git rev-list HEAD -- Documentation/
----------

* 지난 1년 동안 작성된, 모든 브랜치, 태그 또는 기타 ref에 있는 커밋 목록을 출력합니다.
+
----------
git rev-list --author=you@example.com --since=1.year.ago --all
----------

* 현재 브랜치에서 도달 가능한 객체 목록을 출력합니다 (즉, 모든 커밋과 포함된 blob 및 tree).
+
----------
git rev-list --objects HEAD
----------

* 도달 가능한 모든 객체의 디스크 크기, reflog에서 도달 가능한 객체의 크기, 그리고 패킹된 총 크기를 비교합니다.
이것은 `git repack -ad` 실행이 저장소 크기를 줄일 수 있는지 (도달할 수 없는 객체를 삭제하여), 그리고 reflog 만료가 도움이 될 수 있는지 알려줄 수 있습니다.
+
----------
# 도달 가능한 객체
git rev-list --disk-usage --objects --all
# reflog 포함
git rev-list --disk-usage --objects --all --reflog
# 총 디스크 사용량
du -c .git/objects/pack/*.pack .git/objects/??/*
# du 대안: "size" 및 "size-pack" 필드 합산
git count-objects -v
----------

* 현재 브랜치에서 사용되는 객체를 제외한 각 브랜치의 디스크 크기를 보고합니다.
이것은 저장소 크기가 커지는 데 기여하는 예외적인 경우를 찾을 수 있습니다 (예: 누군가가 실수로 대규모 빌드 아티팩트를 커밋한 경우).
+
----------
git for-each-ref --format='%(refname)' |
while read branch
do
	size=$(git rev-list --disk-usage --objects HEAD..$branch)
	echo "$size $branch"
done |
sort -n
----------

* 한 그룹의 ref에 있는 브랜치의 온디스크 크기를 비교하고 다른 그룹을 제외합니다.
여러 원격 저장소의 객체를 단일 저장소에 혼합하는 경우, 어떤 원격 저장소가 저장소 크기에 기여하는지 보여줄 수 있습니다 (예: `origin`의 크기를 기준으로).
+
----------
git rev-list --disk-usage --objects --remotes=$suspect --not --remotes=origin
----------
