git-gui(1)
==========

NAME
----
git-gui - Git용 포터블 그래픽 인터페이스

SYNOPSIS
--------
[verse]
'git gui' [<command>] [<arguments>]

DESCRIPTION
-----------
Git용 Tcl/Tk 기반 그래픽 사용자 인터페이스입니다. 'git gui'는 사용자가
저장소의 변경 사항을 새로운 커밋 생성, 기존 커밋 수정, 브랜치 생성,
로컬 병합 수행, 원격 저장소 가져오기/푸시를 통해 만들 수 있도록 하는 데 중점을 둡니다.

'gitk'와 달리 'git gui'는 커밋 생성 및 단일 파일 주석에 중점을 두며
프로젝트 기록을 표시하지 않습니다. 그러나 'git gui' 내에서 'gitk' 세션을
시작하는 메뉴 동작을 제공합니다.

'git gui'는 인기 있는 모든 UNIX 시스템, Mac OS X 및 Windows (Cygwin 및 MSYS 모두)에서
작동하는 것으로 알려져 있습니다. 가능한 범위 내에서 OS별 사용자 인터페이스
지침을 따르므로 'git gui'는 사용자에게 상당히 네이티브 인터페이스입니다.

COMMANDS
--------
blame::
	주어진 버전(또는 지정되지 않은 경우 워킹 디렉토리)에서
	지정된 파일에 대한 blame 뷰어를 시작합니다.

browser::
	지정된 커밋의 모든 파일을 표시하는 트리 브라우저를 시작합니다.
	브라우저를 통해 선택한 파일은 blame 뷰어에서 열립니다.

citool::
	'git gui'를 시작하고 종료 및 쉘로 돌아가기 전에 정확히 하나의
	커밋을 수행하도록 배열합니다. 인터페이스는 커밋 작업으로만 제한되어
	애플리케이션의 시작 시간을 약간 줄이고 메뉴 표시줄을 단순화합니다.

version::
	현재 실행 중인 'git gui' 버전을 표시합니다.


Examples
--------
`git gui blame Makefile`::

	현재 워킹 디렉토리의 'Makefile' 파일 내용을 표시하고
	각 줄의 원본 작성자 및 해당 줄을 현재 위치로 이동시킨 사람에 대한
	주석을 제공합니다. 커밋되지 않은 파일에 주석이 달리고,
	커밋되지 않은 변경 사항(있는 경우)은 명시적으로 'Not Yet Committed'로
	속성이 부여됩니다.

`git gui blame v0.99.8 Makefile`::

	'v0.99.8' 리비전의 'Makefile' 내용을 표시하고 각 줄에 대한
	주석을 제공합니다. 위의 예와 달리 파일은 워킹 디렉토리가 아닌
	오브젝트 데이터베이스에서 읽습니다.

`git gui blame --line=100 Makefile`::

	위에서 설명한 대로 주석을 로드하고 보기를 자동으로 스크롤하여
	'100'번째 줄에 중앙을 맞춥니다.

`git gui citool`::

	하나의 커밋을 수행하고 완료되면 쉘로 돌아갑니다.
	이 명령은 창이 커밋을 만드는 것 외의 다른 방법으로 닫힌 경우
	0이 아닌 종료 코드를 반환합니다.

`git gui citool --amend`::

	인터페이스의 '마지막 커밋 수정' 모드로 자동 진입합니다.

`git gui citool --nocommit`::

	일반 citool처럼 작동하지만, 커밋을 만드는 대신 0 종료 코드로
	종료됩니다. 아직 병합되지 않은 항목이 인덱스에 포함되어 있지 않은지
	확인하므로 linkgit:git-mergetool[1]의 GUI 버전으로 사용할 수 있습니다.

`git citool`::

	`git gui citool` (위)와 동일합니다.

`git gui browser maint`::

	'maint' 브랜치의 트리용 브라우저를 표시합니다. 브라우저에서
	선택한 파일은 내부 blame 뷰어로 볼 수 있습니다.

SEE ALSO
--------
linkgit:gitk[1]::
	Git 저장소 브라우저. 브랜치, 커밋 기록 및 파일 차이를 표시합니다.
	gitk는 'git gui'의 Repository Visualize 동작에서 시작되는 유틸리티입니다.

Other
-----
'git gui'는 실제로 독립적인 프로젝트로 유지 관리되지만, 안정적인 버전은
최종 사용자 편의를 위해 Git 제품군으로 배포됩니다.

'git gui' 프로젝트의 공식 저장소는 다음에서 찾을 수 있습니다:

  https://github.com/j6t/git-gui
