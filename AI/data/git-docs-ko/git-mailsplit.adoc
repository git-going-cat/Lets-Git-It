git-mailsplit(1)
================

NAME
----
git-mailsplit - 간단한 UNIX mbox 분할 프로그램

SYNOPSIS
--------
[verse]
'git mailsplit' [-b] [-f<nn>] [-d<prec>] [--keep-cr] [--mboxrd]
		-o<directory> [--] [(<mbox>|<Maildir>)...]

DESCRIPTION
-----------
mbox 파일이나 Maildir을 다음과 같은 파일 목록으로 분할합니다: 지정된 디렉토리에 "0001" "0002" .. 와 같이 하여 이후 처리를 할 수 있도록 합니다.

중요: Maildir 분할은 올바른 순서로 패치를 출력하기 위해 파일 이름이 정렬되어야 합니다.

OPTIONS
-------
<mbox>::
	분할할 mbox 파일입니다. 지정되지 않으면 mbox는 표준 입력에서 읽어옵니다.

<Maildir>::
	분할할 Maildir의 루트입니다. 이 디렉토리는 cur, tmp
	및 new 하위 디렉토리를 포함해야 합니다.

-o<directory>::
	개별 메시지를 배치할 디렉토리입니다.

-b::
	파일이 From 라인으로 시작하지 않으면 오류를 신호하는 대신
	단일 메일 메시지로 가정합니다.

-d<prec>::
	기본값인 선행 0이 있는 4자리 대신
	생성된 파일 이름에 대해 다른 정밀도를 지정할 수 있습니다.

-f<nn>::
	처음 <nn>개의 번호를 건너뜁니다. 예를 들어 -f3이 지정되면
	번호 매기기를 0004로 시작합니다.

--keep-cr::
	`\r\n`으로 끝나는 줄에서 `\r`을 제거하지 않습니다.

--mboxrd::
	입력이 "mboxrd" 형식이고 "^>+From " 라인 이스케이프가
	반전되었습니다.
