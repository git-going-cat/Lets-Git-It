git-write-tree(1)
=================

NAME
----
git-write-tree - 현재 인덱스에서 트리 객체 생성


SYNOPSIS
--------
[synopsis]
git write-tree [--missing-ok] [--prefix=<prefix>/]

DESCRIPTION
-----------
현재 인덱스를 사용하여 트리 객체를 생성합니다. 새 트리 객체의 이름은 표준 출력으로 인쇄됩니다.

인덱스는 완전히 머지된 상태여야 합니다.

개념적으로, `git write-tree`는 현재 인덱스 내용을 트리 파일 세트로 동기화합니다(sync()).
현재 디렉토리에 있는 내용과 일치하도록 하려면 `git write-tree`를 수행하기 전에 `git update-index` 단계를 수행해야 합니다.


OPTIONS
-------
`--missing-ok`::
	일반적으로 `git write-tree`는 디렉토리가 참조하는 객체가 객체 데이터베이스에 존재하도록 보장합니다. 이 옵션은 이 검사를 비활성화합니다.

`--prefix=<prefix>/`::
	_<prefix>_ 의 하위 디렉토리를 나타내는 트리 객체를 작성합니다. 이는 이름이 지정된 하위 디렉토리에 있는 하위 프로젝트의 트리 객체를 작성하는 데 사용할 수 있습니다.
