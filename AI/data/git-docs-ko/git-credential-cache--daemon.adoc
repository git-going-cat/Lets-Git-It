git-credential-cache{litdd}daemon(1)
====================================

NAME
----
git-credential-cache--daemon - 임시로 사용자 자격 증명을 메모리에 저장

SYNOPSIS
--------
[verse]
'git credential-cache{litdd}daemon' [--debug] <socket-path>

DESCRIPTION
-----------

NOTE: 이 명령을 직접 호출해서는 안 됩니다. linkgit:git-credential-cache[1]을 사용할 때 자동으로 시작됩니다.

이 명령은 `<socket-path>`에서 지정된 Unix 도메인 소켓에서 `git-credential-cache` 클라이언트를 기다립니다. 클라이언트는 자격 증명을 저장하고 검색할 수 있습니다. 각 자격 증명은 클라이언트가 지정한 타임아웃 동안 유지됩니다. 더 이상 자격 증명이 없으면 데몬이 종료됩니다.

`--debug` 옵션이 지정되면 데몬은 stderr 스트림을 닫지 않으며 클라이언트를 기다리기 시작한 후에도 추가 진단 정보를 출력할 수 있습니다.
