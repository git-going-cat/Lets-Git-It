git-count-objects(1)
====================

NAME
----
git-count-objects - 언팩된 객체 수와 디스크 사용량을 계산합니다.

SYNOPSIS
--------
[verse]
'git count-objects' [-v] [-H | --human-readable]

DESCRIPTION
-----------
언팩된 객체 파일 수와 해당 파일들이 소비하는 디스크 공간을 계산하여,
언제 저장소를 다시 패킹하는 것이 좋은 시점인지 판단하는 데 도움을 줍니다.

OPTIONS
-------
-v::
--verbose::
	더 상세한 보고를 제공합니다:
+
count: 루즈(loose) 객체의 수
+
size: 루즈 객체들이 소비하는 디스크 공간 (KiB 단위, -H 옵션 미사용 시)
+
in-pack: 패킹된(in-pack) 객체의 수
+
packs: 패크 파일(pack file)의 수
+
size-pack: 패크 파일들이 소비하는 디스크 공간 (KiB 단위, -H 옵션 미사용 시)
+
prune-packable: 패크에도 존재하는 루즈 객체의 수. 이 객체들은 `git prune-packed`를 사용하여 제거될 수 있습니다.
+
garbage: 객체 데이터베이스에서 유효한 루즈 객체도 아니고 유효한 패크 파일도 아닌 파일의 수
+
size-garbage: 가비지 파일들이 소비하는 디스크 공간 (KiB 단위, -H 옵션 미사용 시)
+
alternate: 대체 객체 데이터베이스의 절대 경로; 여러 번 나타날 수 있으며, 경로당 한 줄로 표시됩니다. 경로에 출력 불가능한 문자가 포함된 경우, 큰따옴표로 둘러싸여 있고 C 스타일 백슬래시 이스케이프 시퀀스를 포함할 수 있습니다.

-H::
--human-readable::

크기를 사람이 읽기 쉬운 형식으로 출력합니다.
