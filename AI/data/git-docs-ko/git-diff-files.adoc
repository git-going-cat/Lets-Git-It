git-diff-files(1)
=================

NAME
----
git-diff-files - 워킹 트리와 인덱스의 파일을 비교합니다.


SYNOPSIS
--------
[verse]
'git diff-files' [-q] [-0 | -1 | -2 | -3 | -c | --cc] [<common-diff-options>] [<path>...]

DESCRIPTION
-----------
워킹 트리와 인덱스의 파일을 비교합니다.  경로가 지정된 경우
해당 이름의 경로만 비교합니다.  그렇지 않으면 인덱스의 모든 항목이
비교됩니다.  출력 형식은 'git diff-index' 및 'git diff-tree'와
동일합니다.

OPTIONS
-------
include::diff-options.adoc[]

-1 --base::
-2 --ours::
-3 --theirs::
-0::
	각각 "기본" 버전, "우리 브랜치" 또는 "그들 브랜치"와 비교합니다.
	이 옵션을 사용하면 머지된 항목의 diff는 표시되지 않습니다.
+
기본값은 우리 브랜치(-2)와 깨끗하게 해결된 경로와 비교하는 것입니다.
머지되지 않은 항목에 대한 diff 출력을 생략하고 "Unmerged"만 표시하려면
-0 옵션을 사용할 수 있습니다.

-c::
--cc::
	이 옵션은 스테이지 2(우리 브랜치), 스테이지 3(그들 브랜치),
	그리고 워킹 트리 파일을 비교하고 'diff-tree'가 해당 플래그로
	머지 커밋을 표시하는 방식과 유사한 통합 diff를 출력합니다.

-q::
	존재하지 않는 파일에 대해서도 침묵을 유지합니다.
