git-credential-cache(1)
=======================

NAME
----
git-credential-cache - 비밀번호를 일시적으로 메모리에 저장하는 헬퍼

SYNOPSIS
--------
-----------------------------
git config credential.helper 'cache [<options>]'
-----------------------------

DESCRIPTION
-----------

이 명령어는 향후 Git 프로그램에서 사용할 자격 증명을 캐시합니다.
저장된 자격 증명은 파일에 기록되는 대신 캐시-데몬 프로세스의
메모리에 유지되며 구성 가능한 타임아웃 후 잊혀집니다.
캐시-데몬이 종료되면 (예: 시스템이 재시작될 때) 자격 증명이 더 일찍 잊혀집니다.
캐시에 접근하려면 Unix 도메인 소켓을 사용하며, 파일 시스템 권한으로
현재 사용자에게 제한됩니다.

이 명령어를 직접 호출하는 것은 아마도 원하지 않을 것입니다. Git의
다른 부분에서 자격 증명 헬퍼로 사용하도록 되어 있습니다.
linkgit:gitcredentials[7] 또는 아래 `EXAMPLES`를 참조하십시오.

OPTIONS
-------

--timeout <seconds>::

	자격 증명을 캐시할 시간(초) (기본값: 900).

--socket <path>::

	실행 중인 캐시 데몬에 연락하거나 (시작되지 않은 경우 새
	캐시 데몬 시작) `<path>`를 사용합니다.
	`~/.git-credential-cache/`가 존재하는 경우
	`~/.git-credential-cache/socket`이 사용되는 것을 제외하고는
	기본값은 `$XDG_CACHE_HOME/git/credential/socket`입니다.
	홈 디렉토리가 네트워크 마운트된 파일 시스템에 있다면,
	로컬 파일 시스템으로 변경해야 할 수 있습니다. 절대 경로를
	지정해야 합니다.

CONTROLLING THE DAEMON
----------------------

데몬이 타임아웃 전에 모든 캐시된 자격 증명을 잊고 조기에 종료하도록 하려면,
`exit` 액션을 실행할 수 있습니다:

--------------------------------------
git credential-cache exit
--------------------------------------

EXAMPLES
--------

이 헬퍼의 목적은 사용자 이름이나 비밀번호를 입력해야 하는 횟수를 줄이는 것입니다.
예를 들어:

------------------------------------
$ git config credential.helper cache
$ git push http://example.com/repo.git
Username: <사용자 이름을 입력하세요>
Password: <비밀번호를 입력하세요>

[5분 더 작동]
$ git push http://example.com/repo.git
[자격 증명이 자동으로 사용됩니다]
------------------------------------

credential.helper 구성 변수를 통해 옵션을 제공할 수 있습니다 (이 예제는
캐시 시간을 1시간으로 늘립니다):

-------------------------------------------------------
$ git config credential.helper 'cache --timeout=3600'
-------------------------------------------------------

PERSONAL ACCESS TOKENS
----------------------

일부 원격 저장소는 무작위로 생성되어 기억하기 어려운 개인 액세스 토큰을
받아들입니다. 일반적으로 몇 주 또는 몇 달의 수명을 가집니다.

git-credential-cache는 개인 액세스 토큰의 영구 저장에 본질적으로
부적합합니다. 자격 증명은 캐시 타임아웃 후에 잊혀집니다.
긴 타임아웃을 구성하더라도 데몬이 종료되면 자격 증명이 잊혀집니다.

개인 액세스 토큰을 자주 다시 생성하는 것을 피하려면, 영구 저장 기능이
있는 자격 증명 헬퍼를 구성하십시오. 또는 OAuth 자격 증명 헬퍼를
구성하여 자격 증명을 자동으로 생성하십시오.
linkgit:gitcredentials[7], "Available helpers" 및 "OAuth" 섹션을
참조하십시오.
