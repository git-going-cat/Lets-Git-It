git-stripspace(1)
=================

NAME
----
git-stripspace - 불필요한 공백 제거


SYNOPSIS
--------
[verse]
'git stripspace' [-s | --strip-comments]
'git stripspace' [-c | --comment-lines]

DESCRIPTION
-----------

Git에서 사용하는 방식으로 텍스트 (커밋 메시지, 노트, 태그, 브랜치 설명 등)를 표준 입력으로부터 읽어 정리합니다.

인수 없이 실행하면 다음을 수행합니다:

- 모든 줄에서 후행 공백 제거
- 연속된 빈 줄을 하나의 빈 줄로 압축
- 입력 시작과 끝의 빈 줄 제거
- 필요한 경우 마지막 줄에 누락된 '\n' 추가

입력이 공백 문자로만 구성된 경우, 출력은 생성되지 않습니다.

*참고*: 이는 메타데이터 정리를 위한 것입니다. 저장소 내 패치 또는 파일의 공백 수정을 위해서는 linkgit:git-apply[1]의 `--whitespace=fix` 모드를 선호하십시오.

OPTIONS
-------
-s::
--strip-comments::
	주석 문자 (`core.commentChar`, 기본값 `#`)로 시작하는 모든 줄을 건너뛰고 제거합니다.

-c::
--comment-lines::
	각 줄 앞에 주석 문자와 공백을 붙입니다. 줄은 자동으로 줄바꿈 문자로 종료됩니다. 빈 줄에는 주석 문자만 앞에 붙습니다.

EXAMPLES
--------

줄 끝에 '$' 표시가 있는 다음과 같은 노이즈가 많은 입력이 주어졌을 때:

---------
|A brief introduction   $
|   $
|$
|A new paragraph$
|# with a commented-out line    $
|explaining lots of stuff.$
|$
|# An old paragraph, also commented-out. $
|      $
|The end.$
|  $
---------

인수 없이 'git stripspace'를 사용하여 다음을 얻습니다:

---------
|A brief introduction$
|$
|A new paragraph$
|# with a commented-out line$
|explaining lots of stuff.$
|$
|# An old paragraph, also commented-out.$
|$
|The end.$
---------

'git stripspace --strip-comments'를 사용하여 다음을 얻습니다:

---------
|A brief introduction$
|$
|A new paragraph$
|explaining lots of stuff.$
|$
|The end.$
---------
