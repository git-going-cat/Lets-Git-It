git-pack-redundant(1)
=====================

NAME
----
git-pack-redundant - 중복되는 팩 파일 찾기


SYNOPSIS
--------
[verse]
'git pack-redundant' [--verbose] [--alt-odb] (--all | <pack-filename>...)

WARNING
-------
`git pack-redundant`는 더 이상 사용되지 않으며 향후 Git 버전에서 제거될 예정입니다.
개별 중복 객체가 아닌 전체 중복 팩만 제거할 수 있으므로, 일반적으로 저장소 크기를 줄이는 데 유용한 도구가 아닙니다.
대신 `git gc`를 사용하여 객체를 새 팩으로 옮기고 중복을 제거하는 것이 좋습니다.

이 릴리스에서는 `--i-still-use-this` 플래그 없이 `pack-redundant`를 실행하면 실패합니다.
`pack-redundant`가 더 적합하고 이 제거에 반대하는 사용 사례가 있다고 생각되면
git@vger.kernel.org로 Git 메일링 리스트에 문의하십시오.
리스트에 대한 자세한 내용은 https://git-scm.com/community 에서 확인할 수 있습니다.

DESCRIPTION
-----------
이 프로그램은 저장소의 어떤 팩이 중복되는지 계산합니다.
출력은 저장소 루트에서 `xargs rm`으로 파이프하는 데 적합합니다.

'git pack-redundant'는 표준 입력으로 객체 목록을 받습니다.
제공된 객체는 어떤 팩이 필요한지 확인할 때 무시됩니다.
이를 통해 도달할 수 없는 객체를 포함하는 팩을 제거하려는 경우 다음 명령이 유용합니다.

git fsck --full --unreachable | cut -d ' ' -f3 | \
git pack-redundant --all | xargs rm

OPTIONS
-------


--all::
	모든 팩을 처리합니다. 명령줄에 있는 모든 파일 이름은 무시됩니다.

--alt-odb::
	대체 객체 데이터베이스(odb) 디렉토리의 팩에 있는 객체가
	로컬 팩에 존재해야 한다고 요구하지 않습니다.

--verbose::
	stderr로 일부 통계를 출력합니다. 성능에 약간의 페널티가 있습니다.
