git-unpack-objects(1)
=====================

NAME
----
git-unpack-objects - 압축된 아카이브에서 객체 압축 풀기


SYNOPSIS
--------
[verse]
'git unpack-objects' [-n] [-q] [-r] [--strict]


DESCRIPTION
-----------
표준 입력에서 압축된 아카이브(.pack)를 읽어, 포함된 객체들을 확장하고
저장소에 "느슨한"(객체당 하나의 파일) 형식으로 씁니다.

저장소에 이미 존재하는 객체는 팩 파일에서 압축 해제되지 않습니다.
따라서 이 명령을 대상으로 하는 저장소 내의 팩 파일에 대해 사용하면 아무것도 압축 해제되지 않습니다.

새로운 팩을 생성하거나 기존 팩을 교체하는 옵션은 linkgit:git-repack[1]을 참조하십시오.

OPTIONS
-------
-n::
        Dry run. 객체를 실제로 압축 해제하지 않고 팩 파일을 확인합니다.

-q::
	명령은 일반적으로 진행률 퍼센티지를 표시합니다.
	이 플래그는 이를 억제합니다.

-r::
	손상된 팩 파일을 압축 해제할 때, 명령은 첫 번째 손상에서 종료됩니다.
	이 플래그는 계속 진행하고 가능한 많은 객체를 복구하도록 최선의 노력을 다하도록 지시합니다.

--strict::
	깨진 내용이나 링크가 있는 객체는 작성하지 않습니다.

--max-input-size=<size>::
	팩이 <size>보다 클 경우 종료합니다.
