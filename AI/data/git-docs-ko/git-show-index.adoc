git-show-index(1)
=================

NAME
----
git-show-index - Show packed archive index


SYNOPSIS
--------
[verse]
'git show-index' [--object-format=<hash-algorithm>] < <pack-idx-file>


DESCRIPTION
-----------
Git packfile (linkgit:git-pack-objects[1] 또는 linkgit:git-index-pack[1]으로 생성된)에 대한 `.idx` 파일을 표준 입력으로부터 읽어와 그 내용을 덤프합니다. 출력은 한 줄에 하나의 객체로 구성되며, 각 줄에는 공백으로 구분된 두세 개의 열이 포함됩니다:

  - 첫 번째 열은 해당 packfile 내 객체의 바이트 단위 오프셋입니다.

  - 두 번째 열은 객체의 객체 ID입니다.

  - 인덱스 버전이 2 이상인 경우, 세 번째 열에는 객체 데이터의 CRC32 값이 포함됩니다.

객체들은 인덱스 파일에서 발견된 순서대로 출력되며, (올바르게 구성된 파일의 경우) 객체 ID별로 정렬되어야 합니다.

packfile에 대한 더 많은 정보를 얻으려면 linkgit:git-verify-pack[1]을 호출할 수 있다는 점에 유의하십시오. 그러나 이 명령은 인덱스 파일 자체만 고려하므로 더 빠르고 유연합니다.

OPTIONS
-------

--object-format=<hash-algorithm>::
	인덱스 파일에 대한 지정된 객체 형식(해시 알고리즘)을 지정합니다. 유효한 값은 'sha1'과 (활성화된 경우) 'sha256'입니다. 기본값은 현재 저장소의 알고리즘 (`extensions.objectFormat`으로 설정됨)이거나, 값이 설정되지 않았거나 저장소 외부인 경우 'sha1'입니다.
