git-mktree(1)
=============

NAME
----
git-mktree - `ls-tree` 형식 텍스트에서 트리 객체 빌드


SYNOPSIS
--------
[verse]
'git mktree' [-z] [--missing] [--batch]

DESCRIPTION
-----------
비재귀적인 `ls-tree` 출력 형식으로 표준 입력을 읽어 트리 객체를 생성합니다. `mktree`는 트리 항목의 순서를 정규화하므로 입력의 사전 정렬이 필요하지 않습니다. 빌드된 트리 객체의 객체 이름이 표준 출력으로 기록됩니다.

OPTIONS
-------
-z::
	NUL로 종료되는 `ls-tree -z` 출력을 대신 읽습니다.

--missing::
	누락된 객체를 허용합니다. 기본 동작 (이 옵션 없이)은 각 트리 항목의 해시가 기존 객체를 식별하는지 확인하는 것입니다. 이 옵션은 gitlink 항목 (별칭 "서브모듈") 처리에는 영향을 미치지 않으며, 이들은 항상 누락되도록 허용됩니다.

--batch::
	종료하기 전에 여러 개의 트리 객체를 빌드할 수 있습니다. 각 트리는 단일 빈 줄로 구분됩니다. 마지막 줄바꿈은 선택 사항입니다. 참고 - `-z` 옵션이 사용되면 줄은 NUL로 종료됩니다.
