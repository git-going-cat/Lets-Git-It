## 💡 핵심 차별점

<br>

### 1. 게임이 곧 Git 학습이다

단순히 "Git을 테마로 한 게임"이 아닙니다.  
게임에서 입력하는 모든 명령어는 **실제 Git 워크플로우 그대로**입니다.

```bash
git add .
git commit -m "fix: login bug"
git push origin main
git merge feature/login
```

게임을 플레이하고 나면 Git 명령어가 **체화**됩니다.

<br>

### 2. 혼자 해도, 같이 해도 재밌다

| 모드 | 인원 | 경험 |
|------|------|------|
| **싱글** | 1명 | 난이도별 Git 학습, 내 실력을 랭킹으로 확인 |
| **스피드런** | 2~4명 | 같은 명령어를 먼저 치는 사람이 기여도 획득 |
| **타임어택** | 2명 | 3분 안에 main 브랜치에 더 많이 push한 사람 승리 |
| **협력** | 4명 | 각자 명령어를 나눠 가져 팀이 함께 형상 완성 |

<br>

### 3. 단계별 학습 설계

Easy → Normal → Hard로 갈수록 더 복잡한 Git 개념이 등장합니다.

```
Easy   →  add, commit, push, merge, checkout, pull
Normal →  + fetch (checkout은 스스로 판단해야 함)
Hard   →  + rebase, force push, diff, conflict 해결
```

게임을 클리어하다 보면 자연스럽게 **Git의 깊이 있는 개념**까지 익히게 됩니다.

<br>

### 4. Conflict도 게임이 된다

어렵고 무섭게만 느껴지던 Git conflict.  
**Let's Git It**에서는 방향키로 해결하는 미니게임으로 만났습니다.  
conflict를 만나도 당황하지 않는 개발자가 됩니다.
